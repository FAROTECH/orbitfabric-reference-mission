# Engineering Story 01 - One Mission Contract Across Flight and Ground

Status: **implementation in progress**

This directory is the executable package for the first OrbitFabric Engineering Story.

The final narrative is intentionally not written yet. The Story is evidence-led:

```text
engineering question
    -> executable design
    -> native implementation
    -> retained evidence
    -> claim audit
    -> final narrative
```

## Selected proof

The package uses the canonical Reference Mission identities:

```text
command
    payload.stop_acquisition

telemetry
    radiation_payload.acquisition_active
```

and will test whether one mission contract can independently drive:

```text
OrbitFabric Core
    -> F Prime adapter -> native F Prime realization

same mission / Core identity
    -> OpenC3 COSMOS adapter -> native verification procedure
```

with downstream convergence through the existing OpenC3 F Prime plugin and a live F Prime target.

```text
example/

evidence/

```

## Non-claims at this stage

This work does not claim:

- full Reference Mission execution in F Prime;
- flight behavior generated by OrbitFabric;
- COSMOS dictionary generation by the OrbitFabric COSMOS adapter;
- serial composition of the two OrbitFabric adapters;
- a completed runtime proof.

The F Prime implementation behavior used by this Story will remain an explicit Story-owned downstream fixture.
